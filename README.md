## 🔬 Research & Key Projects

*   **Spotlight Paper (IEEE IJCB 2026):** *"F-BioGate: A Multimodal Dataset for Frontal Video-based Gait Biometric Recognition"* (Published on IEEE Xplore). Extracted robust spatiotemporal features using RGB-D, infrared, and IMU data to tackle frontal gait recognition. [Code available on GitHub].
*   **AuraCoach:** A distributed multi-platform ecosystem (iOS, watchOS, macOS) designed to mitigate public speaking anxiety using Calm Technology, Affective Computing, and LLaMA-3.3 for asynchronous AI mentorship.
*   **Kinetic Sight CosmOS:** An experimental web-based multimodal interface for touchless 3D Solar System exploration, solving the "Midas Touch" problem by decoupling Gaze, Hand Pinch, and Speech inputs.
*   **Multi-Task Learning via Model Merging:** Mitigated catastrophic forgetting in NLP by fusing "Task Vectors" in the latent space (TIES-Merging), unifying a DistilBERT encoder for both Toxicity and SMS Spam Detection.
*   **Task Arithmetic for Machine Unlearning:** Explored GDPR's "Right to be Forgotten" in CNNs (VGG-11, ResNet-18) using surgical ablation via Task Arithmetic to erase specific data classes without full model retraining.
*   **Semantic Transplantation in Diffusion Models:** Extended the "Semantic Surgery" paradigm in Text-to-Image models for precise zero-shot concept replacement via CLIP embedding manipulation in the Stable Diffusion latent space.
*   **Deep Learning for Level Popularity Prediction (Super Mario Maker 2):** Designed a multimodal mega-ensemble (Vision, Sequence, Metadata) achieving 86.38% accuracy in predicting level popularity from raw binary data.
*   **Interdisciplinary Computational Thinking:** Co-developed educational frameworks bridging Physics, Biology, and Music with C++, Prolog, and Snap! to teach advanced programming paradigms.
